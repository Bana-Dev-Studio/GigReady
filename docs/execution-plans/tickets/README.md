# Frontend Tickets

Este directorio divide las fases frontend en tickets chicos y ejecutables.

## Formato

- `phaseX-tareaY`
- Cada ticket debe incluir:
  - Requerimiento
  - Forma de encararlo
  - Orientación mínima
  - Criterios de aceptación
