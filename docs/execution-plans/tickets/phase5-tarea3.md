# phase5-tarea3 - Páginas de producto y casos de uso

## Requerimiento
Crear páginas o secciones específicas que expliquen usos concretos del producto y capturen búsquedas de intención de producto.

## Forma de encararlo
- Definir páginas o secciones para bandas, worship teams y ensayos con stems.
- Escribir copy natural con términos relacionados al uso real del producto.
- Incluir preguntas frecuentes cortas para responder dudas comunes.
- Añadir enlaces internos entre estas páginas y la home.

## Orientación mínima
El contenido debe responder a necesidades reales del usuario y reforzar el posicionamiento de valor del producto.

## Criterios de aceptación
- Existen páginas o secciones con enfoque claro de uso y audiencia.
- El copy está orientado a problemas concretos del usuario.
- Hay una estructura de navegación interna coherente.
