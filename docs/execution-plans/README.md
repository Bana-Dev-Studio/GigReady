# Execution Plans

Este directorio traduce el roadmap vigente en planes de ejecución concretos y tomables por cualquier desarrollador.

## Cómo usar estos planes

- Tomar una fase completa, no mezclar fases.
- Ejecutar los pasos en orden.
- Validar cada paso con tests, build o revisión funcional antes de avanzar.
- Si una tarea depende de backend externo, tratarla como contrato y no como implementación local.

## Tickets frontend

Para ejecución más granular, usar el índice de tickets en [tickets/README.md](tickets/README.md).
